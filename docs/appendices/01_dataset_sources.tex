\chapter{Dataset sources}
\label{apx:dataset_sources}
The following is the complete list of external sources used to build the \texttt{full} and \texttt{mid} tiers of \texttt{Marek324/speech-music-classification} (see \cref{cap:dataset}). \textcolor{green}{check licences, not sure if the dataset can be public}
The crit tier additionally uses hand-recorded clips and synthetic mixes derived from the same sources; those are enumerated in \texttt{scripts/dataset/crit/manifest.toml}.

\begin{itemize}
    \item \textbf{Speech:}
    \begin{itemize}
        \item LibriSpeech ASR --- \texttt{train.360} (clean) and \texttt{train.500} (other) splits, used for the \texttt{speech\_clean} and \texttt{speech\_dirty} subclasses respectively. \url{https://hf.co/datasets/openslr/librispeech_asr}
    \end{itemize}

    \item \textbf{Music:}
    \begin{itemize}
        \item Free Music Archive (FMA, Hugging Face mirror) --- six genres (\texttt{instrumental}, \texttt{electronic}, \texttt{pop}, \texttt{rock}, \texttt{hip-hop}, \texttt{folk}) selected via genre filtering. \url{https://hf.co/datasets/rpmon/fma-genre-classification}
        \item Bel Canto --- used for the \texttt{music\_acapella} subclass (the music subclass closest to speech in feature space). \url{https://hf.co/datasets/ccmusic-database/bel_canto}
    \end{itemize}

    \item \textbf{Inactive (environmental noise):}
    \begin{itemize}
        \item DEMAND acoustic-noise corpus --- $18$ environmental noise recordings, used for the \texttt{noise} subclass. \url{https://hf.co/datasets/voice-biomarkers/DEMAND-acoustic-noise}
    \end{itemize}
\end{itemize}

The synthetic speech subclasses (\texttt{speech\_multispeaker}, \texttt{speech\_som}, \texttt{speech\_msom}, \texttt{speech\_noisy}) are generated deterministically at build time from the sources above by \texttt{scripts/dataset/augmentation.py}.
They introduce no new external data.
